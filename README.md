# ⚡ S.P.D MORPH ENGINE

An interactive Power Rangers SPD inspired morphing simulator built using **Three.js**, **MediaPipe Hand Tracking**, and cinematic shader-based particle effects.

Real-time hand gestures trigger futuristic ranger transformations directly inside the browser.

---

# 🚨 Features

* ⚡ Real-time Hand Gesture Detection
* 🔴 SPD Red Ranger Morph
* 🔵 SPD Blue Ranger Mode
* ⚪ SPD Shadow Ranger Aura
* 🌌 Mega Mode Transformation
* 🎥 Cinematic Bloom & Screen Shake
* 🔥 Custom GLSL Shader Particles
* 💫 Energy Rings & Morph FX
* 🖐 Live Webcam Scanner System
* 🌐 Browser-Based Real-Time VFX Engine

---

# 🛠 Tech Stack

* HTML5
* CSS3
* JavaScript
* Three.js
* GLSL Shaders
* MediaPipe Hands
* WebGL
